# Задание №7. Вычисление определённого интеграла — Вариант №8

f(x) = 3.7 cos(1.5x) exp(−4x/3) + 2.4 sin(4.5x) exp(2x/3) + 4,
a = 1.8, b = 2.3, α = 0, β = 3/5

## Структура пакета

```
quadrature_project/
├── quadrature/                 # пакет с реализацией методов
│   ├── variant.py              # f(x), p(x), a, b, alpha, beta (вариант 8)
│   ├── moments.py               # аналитические моменты веса (замена переменных)
│   ├── cardano.py               # решение кубического уравнения методом Кардано
│   ├── elementary.py            # левые/средние прямоугольники, трапеции, Симпсон
│   ├── newton_cotes3.py         # составная 3-точечная ИКФ Ньютона-Котеса (с весом)
│   ├── gauss3.py                # составная 3-точечная КФ Гаусса (узлы -- Кардано)
│   ├── reference.py              # эталонное значение интеграла (scipy.quad)
│   └── richardson.py            # метод Ричардсона + правило/процесс Эйткена
├── part1_run.py                 # п.1.1-1.3: графики погрешности, печать АСТ
├── part2_run.py                 # п.2.1-2.2: контроль точности eps=1e-6
├── main.py                      # запускает всё сразу
├── requirements.txt
└── outputs/                     # сюда сохраняются графики (part1_1_errors.png,
                                  #  part1_2_errors.png)
```

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

или по отдельности: `python part1_run.py`, `python part2_run.py`.
